Victory X

Политика конфиденциальности · обновлено 11 ноября 2026

Victory X — расширение для браузера, которое помогает менеджеру работать с лидами в CRM Victory: показывает факты о компании, подсказки по ходу разговора и вносит итог звонка в CRM.

Какие данные обрабатываются

  • Данные CRM. Расширение читает карточку лида, задачи и переписку в CRM Victory, чтобы показать их менеджеру и внести итог звонка. Эти данные передаются только в CRM вашей компании.
  • Данные карт. Название и адрес компании используются для запроса её карточки на Яндекс Картах и 2ГИС — чтобы собрать факты: рейтинг, отзывы, фото, место в выдаче.
  • Настройки. Имя менеджера, цены, правила CRM, код доступа к внутреннему сервису и ключи API (если менеджер их ввёл) хранятся в хранилище браузера на компьютере менеджера.
  • Подсказки ИИ (по желанию). Если менеджер включил ИИ и ввёл ключ, фрагменты разговора и факты лида отправляются выбранному им провайдеру (OpenAI, Anthropic или SpeShu) напрямую, с его ключом.

Чего расширение не делает

  • Не передаёт данные разработчику: у расширения нет собственного сервера.
  • Не продаёт данные и не передаёт их третьим лицам, кроме CRM компании и выбранного провайдера ИИ.
  • Не собирает аналитику, не устанавливает трекеры и не читает другие сайты, кроме доменов из разрешений: victory-crm.ru, yandex.ru, 2gis.ru, coder.afihub.ru и API выбранного провайдера ИИ.
  • Не изменяет код страниц CRM.
  • Не использует данные для оценки кредитоспособности и не для целей, не связанных с работой менеджера.

Хранение и удаление

Все настройки и кэш хранятся локально, в браузере менеджера. Их можно удалить, удалив расширение или очистив данные расширения в настройках браузера. Ключи API и код доступа никуда не отправляются, кроме соответствующих сервисов.
